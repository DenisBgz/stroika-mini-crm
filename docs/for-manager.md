# Объяснение для руководителя

Постановщик создаёт задачи, назначает исполнителей и принимает работу либо возвращает её на доработку с пояснением.

Исполнитель видит только свои задачи. Он не может менять задания, удалять записи или самостоятельно принимать результат.

Вход — по выданным логину и паролю. Права проверяются при каждом обращении к данным. Все смены статусов сохраняются в истории, которую сотрудники не могут изменить или стереть.
