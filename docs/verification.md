# Проверки

Проверено 4 ноября 2026 года:

- `npm test`: 8 тестов, включая 50 сочетаний роли и перехода статуса. Исполняется SQL-миграция в PGlite.
- `npm run test:api`: вход трёх пользователей, закрытая регистрация, изоляция данных, запрет прямых записей и подделки истории, полный цикл доработки.
- `npm run build`: TypeScript и сборка проходят.
- В браузере: операции с объектами и задачами, смена ролей, история, узкий и широкий экран. Ошибок консоли в проверенных сценариях нет.

Нагрузочные испытания, параллельные транзакции и полный охват браузеров не выполнялись.
